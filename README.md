# Начало работы

1. Склонируйте репозиторий в любую подходящую директорию на вашем компьютере.
2. Необходимо переименовать .env.template -> .env и заполнить значения параметров(текущие значения указаны по умолнчанию). 
По крайней мере SECRET необходимо указать свой.
3. Далее в корне проекта выполняем `docker-compose up`. (Предполагается что докер уже установлен)
4. `docker-compose up --build`  - Принудительная пересборка и запуск
